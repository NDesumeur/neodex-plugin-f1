# Formule 1

La saison de F1 : calendrier avec les horaires de chaque séance, compte à rebours, résultats des courses, qualifications et sprints, classements pilotes et écuries.

L'onglet CALENDRIER montre le prochain Grand Prix avec toutes ses séances à l'heure de Paris, puis chaque manche avec son vainqueur. RÉSULTATS : course, qualifications et sprint de n'importe quelle manche. L'étoile d'un pilote le met en avant. Les qualifications et les courses peuvent aller dans ton emploi du temps. Données Jolpica (la suite libre d'Ergast).

Ses données (réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Formule 1 → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
